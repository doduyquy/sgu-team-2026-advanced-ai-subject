# Literature Survey and Related Work

This folder stores course survey material and papers used to understand autonomous-driving method families and future research directions.

The project uses the following method map:

1. Random / Naive
2. Rule-Based / Heuristic
3. Planning / Search
4. Simulation-Based Planning / Look-ahead
5. Learning from Data / Imitation
6. Model-Free Reinforcement Learning
7. Search + Learned Policy / Value
8. Model-Based RL / World Models

This taxonomy helps organize reading and comparisons; it is not a promise to implement every family in the course.

For the implementation roadmap and platform constraints, use [`../STAGE_ROADMAP.md`](../STAGE_ROADMAP.md). Survey papers should not be treated as authoritative documentation of Platform V1 behavior.
