# Literature Survey & Related Work

This directory will store research papers, survey notes, and comparative analyses on autonomous driving decision-making methodologies.

## Scope

- Rule-based and heuristic driving policies (e.g., IDM, MOBIL, safety filters).
- Search and planning techniques (lattice planning, motion primitives, MPC).
- Simulation-based planning (MCTS, rollout planning).
- Imitation learning and behavior cloning.
- Deep reinforcement learning approaches (model-free and model-based).
- Algorithm comparison tables and benchmark references.
