# Autonomous Driving Research Documentation

This directory hosts documentation, simulator investigations, literature review notes, and architectural decision records for the autonomous driving research stream.

## Subdirectories

- `environment/`: Simulator investigation notes, MetaDrive configuration details, observation/action/reward analyses, and environment installation guides.
- `survey/`: Literature survey notes, related work reviews, and algorithm comparison tables.
- `decisions/`: Architecture Decision Records (ADRs) and design choices formalized after team review.
- `logging/`: Logging conventions, metrics specifications, and artifact schemas.
